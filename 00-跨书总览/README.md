# 跨书总览：人工智能的双线学习路线

这两本书不是同一类东西，配起来读刚好互补：

- 《人工智能导论：模型与算法》（吴飞）是**教材**，按技术路线分章，讲"每个方法怎么做"。
- 《人工智能简史》（尼克）是**历史**，按时间与人物分章，讲"每个方法为什么被放弃又被捡起来"。

一本给你骨架，一本给你因果。只读导论，你会知道公式却不知道为什么这些公式能活下来；只读简史，你会知道故事却不会算任何东西。

## 推荐学习顺序

| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 简史 ch01—ch03 | 建立时间轴与路线分裂，不需要任何数学基础 | 能说清符号派与连接派各自的主张与失败模式 |
| 2 | 导论 ch01 | 同一件事的技术版：五种计算范式 | 能对一个任务说出五种做法各自的成本 |
| 3 | 导论 ch02、ch03 + 简史 ch09 | 逻辑、搜索、可计算性，三者共用一套符号工具 | 能手算 A*、能反证停机问题 |
| 4 | 简史 ch04 + 导论 ch04 | 先看神经网络为什么三次起伏，再学监督学习的具体算法 | 能手算最小二乘、信息增益 |
| 5 | 导论 ch05、ch06 | 无监督与深度学习，这是今天的主流 | 能手算 K-means、一轮 EM、卷积尺寸 |
| 6 | 简史 ch05、ch06 + 导论 ch07、ch08 | 强化学习与博弈，两本书讲的是同一批案例 | 能手算 Q 更新、求混合策略均衡 |
| 7 | 简史 ch07、ch08、ch10 + 导论 ch09 | 语言、大模型、趋势，最后收束 | 能解释"预测下一个词"为什么有效，能判断一个场景该走哪条路线 |

## 各书定位（一句话）

- 《人工智能导论：模型与算法》：讲**怎么做**。九章覆盖五种范式，每章有公式、算法步骤、可手算的例子。不适合当小说读，适合配纸笔。
- 《人工智能简史》：讲**为什么**。十一条主线，每条都有一到两个"当时被什么卡住"的判断。适合先建立判断力，再回头补技术细节。

## 学习节奏建议

按每周 6—8 小时算，全程约 10 周：

| 周 | 内容 | 检查点 |
|---|---|---|
| 1 | 简史 ch01—ch03 | 能画出路线分裂图 |
| 2 | 导论 ch01、ch02 | 能翻一阶逻辑式、能说清五种范式 |
| 3 | 导论 ch03 + 简史 ch09 | 手算 A* 与剪枝 |
| 4 | 简史 ch04 + 导论 ch04 前半 | 能手算最小二乘 |
| 5 | 导论 ch04 后半（SVM、集成） | 能算 AdaBoost 一轮 |
| 6 | 导论 ch05 | 手算 K-means 与一轮 EM |
| 7 | 导论 ch06 | 算卷积尺寸、走一遍反向传播 |
| 8 | 简史 ch05、ch06 + 导论 ch07 | 手算 Q 更新 |
| 9 | 导论 ch08 + 简史 ch07、ch08 | 求一个混合均衡 |
| 10 | 简史 ch10、ch11 + 导论 ch09 | 写一份 800 字的场景判断 |

交叉复习的原则：**每学完一个技术方法，回到简史看它当年为什么失败**。这一遍比再读一遍教材有用。
