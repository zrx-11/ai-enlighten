# 从零推导：两个最难的课题

《人工智能导论：模型与算法》里有两处，读文字讲解能看懂"是什么"，但推不出来"为什么"：**反向传播**（6.2.3）和**支持向量机**（4.6）。这两份单文件交互页把那两步从头补上。

## 两份产物

| 网页 | 对应原书 | 章节数 | 从哪儿开始 | 学完能做什么 |
|---|---|---|---|---|
| 03-从零推导-反向传播.html（与 index.html 同目录） | 6.2.3 反向传播 | 12 | 加减乘除与斜率 | 手算一个两层网络的梯度，解释梯度消失的成因与三种解法 |
| 03-从零推导-支持向量机.html（与 index.html 同目录） | 4.6 支持向量机 | 15 | 坐标、直线、距离 | 独立推出最大间隔问题、对偶形式，算出一组具体数据的 w、b 与间隔 |

两份都是单文件、离线可开：KaTeX 连 20 个字体全部内联，断网也不掉公式；移动端按 375px 起步，桌面自动出侧边栏。

## 怎么用

1. 双击打开，默认停在第一章。
2. 手机端左上角 `☰` 打开目录，或直接点顶栏左右箭头翻章。
3. 每章底部有"上一章 / 下一章"，键盘 `←` `→` 也能翻。
4. 自测题点"显示答案"再展开，先自己写。
5. 页面里的滑块是真算的：反向传播页调学习率看损失曲线（η 超过 2 会震荡），支持向量机页调 C 看边界从宽变窄（解由离线求解后内嵌，滑块只在解之间插值）。

## 依赖图（两份页面的第一章都有可视化版本）

```
反向传播：四则运算 → 斜率/导数 → 链式法则 → 偏导与梯度 → 神经元与损失 → 计算图与反向传播
支持向量机：坐标与直线 → 向量/内积/模长 → 点到直线距离 → 分类与 ±1 标签 → 间隔 → 约束优化 → 对偶 → 软间隔与核
```

## 已知边界

- 数字都是自拟的教学数据（反向传播页 x=1、y=3、w=2 一路手算；SVM 页两点对称算例），不是真实数据集。正文里已标注。
- SVM 页的 C 滑块只覆盖 0.01–100 的 12 个解，中间值是对数插值，不代表精确解。
- 不涉及：测度论、泛函分析、SMO 工程实现、Transformer。
