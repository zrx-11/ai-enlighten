# 贝尔曼方程

- **难度**：高难 | **涉及章节**：第 7 章（7.1.4、7.2）

## 一句话定义

贝尔曼方程说：一个状态的价值，等于"当下的奖励"加上"折扣后的下一个状态的价值"。它把长期回报拆成了可以一步步算的递推式。

## 为什么重要

它是所有值函数方法的骨架。Q 学习、DQN、值迭代、策略评估，全都是在不同程度上"解这个方程"或"近似这个方程"。

## 详解

期望形式（评价给定策略 π）：

```
V(s) = Σ_a π(a|s) Σ_s' P(s'|s,a)[r + γV(s')]
```

最优形式（求最好的策略）：

```
V*(s) = max_a Σ_s' P(s'|s,a)[r + γV*(s')]
```

差别只在 `max`。期望形式是线性方程组，可以直接解；最优形式是非线性的，要靠迭代（值迭代）或"评估-改进"循环（策略迭代）。

Q 学习的更新式本质上是贝尔曼最优方程的**采样版**：用一次实际采样 `r + γmaxQ(s',·)` 代替期望。

## 常见误解

**别以为贝尔曼方程要求知道全局**——它只要求"下一步"，这正是它能被采样近似、能在大状态空间里用的原因。
