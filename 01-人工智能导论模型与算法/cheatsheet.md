# 速查表

## 公式与规则

| 场景 | 内容 |
|---|---|
| 一元最小二乘 | `w = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²`，`b = ȳ − w x̄` |
| Sigmoid | `σ(z) = 1/(1+e^(−z))` |
| 信息熵 | `H = −Σ p_k log₂ p_k` |
| 信息增益 | 分裂前熵 − 子集熵的加权平均 |
| AdaBoost 话语权 | `α = 0.5 ln((1−ε)/ε)` |
| AdaBoost 权重更新 | 分错乘 `e^α`，分对乘 `e^(−α)`，再归一化 |
| SVM 间隔 | `2/‖w‖`，约束 `y_i(w·x_i+b) ≥ 1` |
| 软间隔目标 | `(1/2)‖w‖² + C Σ ξ_i` |
| 合页损失 | `max(0, 1 − y(w·x+b))` |
| 高斯核 | `exp(−‖x−z‖²/(2σ²))` |
| 卷积输出尺寸 | `(W − K + 2P)/S + 1` |
| 卷积参数量 | `K×K×输入通道×输出通道` |
| 折扣回报 | `1 + γ + γ² + … = 1/(1−γ)` |
| 贝尔曼期望方程 | `V(s) = Σ π(a|s) Σ P(s'|s,a)[r + γV(s')]` |
| 贝尔曼最优方程 | `V*(s) = max_a Σ P(s'|s,a)[r + γV*(s')]` |
| Q 学习更新 | `Q ← Q + α[r + γ max Q(s',·) − Q]` |
| UCB1 | `胜率 + c·√(ln N_父 / N_子)` |
| 二价拍卖 | 最高价得，付第二高价；如实报价是占优策略 |

## 算法步骤

**A\***
1. 开放表放入起点，`f = g + h`。
2. 取 f 最小的节点，若是目标则结束。
3. 扩展它的邻居，更新 g，若更优则改父节点并放回开放表。
4. 重复 2—3。

**AdaBoost**
1. 初始化样本权重 `1/m`。
2. 训练弱分类器，算加权错误率 ε。
3. 算 `α = 0.5ln((1−ε)/ε)`，加入集成。
4. 按 `e^(±α)` 更新权重并归一化。
5. 重复 T 轮，按 α 加权投票。

**K-means**
1. 初始化 k 个中心。
2. 每个点归最近中心。
3. 每个簇重算重心。
4. 中心不变则停。

**EM**
1. E：算隐变量后验 γ。
2. M：用 γ 加权，最大化似然，更新参数。
3. 似然变化小于阈值则停。

**反向传播**
1. 前向：逐层算 `z = Wx+b`、`a = σ(z)`，保存中间值。
2. 算输出层梯度 `∂L/∂z`。
3. 反向：`∂L/∂W = ∂L/∂z · xᵀ`，`∂L/∂x = Wᵀ · ∂L/∂z`。
4. 更新 `W ← W − lr·∂L/∂W`。

## 复杂度速记

| 算法 | 时间 | 空间 |
|---|---|---|
| 广度优先 | `O(b^d)` | `O(b^d)` |
| 深度优先 | `O(b^m)` | `O(bm)` |
| A*（好 h） | 远小于 `O(b^d)` | 取决于开放表 |
| Alpha-Beta 最优 | `O(b^(d/2))` | `O(bd)` |
| 核方法 | `O(n²)`～`O(n³)` | `O(n²)` |
| 卷积层 | `O(H·W·K²·C_in·C_out)` | 参数 `K²·C_in·C_out` |

## 易混对照

| 容易混 | 区别 |
|---|---|
| 参数 vs 超参数 | 参数由训练得到（权重）；超参数人定（学习率、层数） |
| 判别式 vs 生成式 | 学 `P(y|x)` vs 学 `P(x,y)` |
| 完全信息 vs 完美信息 | 规则公开 vs 当前局面可见 |
| 期望风险 vs 经验风险 | 真实分布上的误差 vs 训练集上的误差 |
| on-policy vs off-policy | 学自己正在用的策略 vs 学另一个策略的数据 |
