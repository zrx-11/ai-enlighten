# 符号主义与连接主义

- **难度**：基础 | **涉及章节**：第 1、2、3、4、11 章

## 一句话定义

符号主义认为智能是"操作符号"，连接主义认为智能是"从数据里拟合出映射"。这是同一门学科里最持久的一次分裂。

## 为什么重要

你读到的几乎每一次"AI 寒冬"和"AI 复兴"，都是这两派势力消长的结果。判断一项新技术属于哪一派，是理解它能力边界的第一步。

## 详解

| | 符号主义 | 连接主义 |
|---|---|---|
| 知识从哪来 | 人写进去的规则 | 从数据里学出来的参数 |
| 典型产物 | 逻辑程序、专家系统、知识图谱 | 感知机、CNN、Transformer |
| 优点 | 可解释、精确、样本需求低 | 适应模糊模式、可扩展、能处理感知 |
| 弱点 | 遇到没写的情况就崩 | 不可解释、需要大量数据 |
| 类比 | 计划经济 | 自由市场经济 |

历史节奏：

1. 1950s—1960s 符号派主导（定理证明、通用问题求解）。
2. 1970s 第一次寒冬，两派都受挫。
3. 1980s 专家系统商业化，符号派回潮；同时反向传播出现。
4. 1990s SVM 压制神经网络，连接主义再受挫。
5. 2012 之后连接主义全面胜出。
6. 2020s 出现融合：神经符号方法、工具调用、检索增强。

## 常见误解

**别以为这是"谁对谁错"的问题**。符号方法在需要精确与可审计的场景（编译器、法律条文、定理证明）至今不可替代；连接方法在感知与生成上无可匹敌。二者是分工。
